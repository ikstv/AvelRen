## Межі 0.1.2

У release notes можна заявляти лише три зміни вище: п’ятий стан Android-плашки
для підтвердженого перезапуску, server-side self-lock fix PR #37 та Android
ID-display PR #38. До публікації потрібні:

- окремо погоджене розгортання #37 із backup, перевіркою та способом відкату;
- AAB з чистого актуального `main`, записом commit, SHA-256 і дати;
- встановлення та перевірка APK на телефоні, зокрема `awaiting_approval` і
  перехід «Технічні роботи» → «Перезапуск сервера» у підтвердженому вікні;
- явний дозвіл на GitHub Release і на подання/публікацію у вибраному Play-треку.

Поки ці умови не виконані, не публікувати GitHub draft, не створювати
публічний tag і не подавати Play release.
