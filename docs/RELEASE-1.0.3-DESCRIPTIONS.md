# Описи 1.0.3 — у підготовці

Власник погодив 07.10.2026 розгорнутий зрозумілий опис у додатку та GitHub,
а для Google Play — скорочений текст із тим самим змістом. Це погоджений
виняток для 1.0.3 з попереднього правила дослівної рівності трьох місць.
Історичні описи 0.1.0–0.1.2 не змінюються.

## Джерела без дублювання

- Додаток «Про додаток» і майбутній GitHub Release читають повністю
  [канонічний опис](../apps/android/app/src/main/assets/release-notes/v1.0.3.uk.txt).
- Для Play використовуємо [короткий опис](release-notes/v1.0.3.play.uk.txt),
  не більше 500 Unicode-символів без кінцевого переносу рядка.

Не копіювати текст у третій окремий файл. При зміні повного опису звірити
короткий вручну: ті самі функції та обмеження, без нових обіцянок. Обидва
тексти проходять verify_android.py; повний опис має захисну межу 5000.
Це перевірка розміру/наявності, не автоматичний доказ змістової рівності.

Немає місячного трафіку або витрат; прогноз не оголошуємо завершеним.
Дата релізу — «у підготовці» до фактичної публікації. Зміна тексту не
публікує GitHub/Play release і не завершує телефонне приймання.

Перестановка налаштувань та перенесення політики — окремий UI-крок.
