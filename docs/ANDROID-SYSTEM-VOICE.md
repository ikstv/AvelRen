# Системний голос зростання черги

Погоджені специфікація й план: PR #87, 04.10.2026.
Локальний прототип пройшов update/cancel/sequence із підтвердженням власника.

Продуктові компоненти готують перевірені PCM WAV у відкритому застосунку,
зберігають їх атомарно в приватних files та відкривають лише готові ключі
через read-only provider. Скасована або невдала підготовка не залишає
записів готовності. Сталі канали поважають вимкнення та зміну звуку Android.

Походження нового коду: AvelRen-ORIGINAL, погоджена специфікація
`docs/superpowers/specs/2026-10-04-system-notification-voice-design.md`.
Бінарні WAV генеруються встановленим локальним TTS, до Git не додаються.

Це запис реалізації кандидата. CI, продуктовий APK, телефон і справжній
FCM приймаються окремо в RELEASE-READINESS.md; цей документ їх не підтверджує.

## Review і виправлення

Незалежний review гілки `ff666c4..1637065` знайшов чотири важливі дефекти.
У єдиному виправному проході додано поведінкові RED→GREEN тести:
перетин deadline всередині publisher не кидає exception; DND/відсутній
ресурс зупиняють звук зі збереженням тихого актуального alert; відсутній
канал використовує резервний показ, а явний NONE не обходиться;
foreground recovery перечитує канали та прибирає усунуту проблему.
Екран має перехід до системних налаштувань для блокування/зміни звуку.

ConnectedTest probe тепер перевіряє лише підготовку. Його окремий шлях
тестових подій відкладено як minor; повна локальна доставка перевіряється
в preview/pushQa через debug receiver. Phone/FCM gate ще відкритий.
