## Перевірка 13 спрацювань — 11.10.2026

Усі 13 початкових спрацювань `generic-api-key` класифіковано як хибні
тривоги на контрольні суми файлів, а не ключі автентифікації:

| Група | Кількість | Доказ |
| --- | ---: | --- |
| SERVER-FILES.csv | 8 | SHA-256 повторно обчислено з вихідних Git blobs; усі збігаються. Вихідні commit/path записані в реєстрі |
| PRODUCTION-AUDIT.md та SERVER-TRANSFER.md | 4 | Контекст точних історичних комітів явно описує SHA-256 API-файлів. Це класифікація тексту, не повторна перевірка сервера |
| Get-ProjectSecret.ps1 | 1 | Значення належить таблиці hashes для архіву; використовується для перевірки asset digest і Get-FileHash, не для автентифікації. Архів не завантажували |

[Реєстр винятків](../tools/consolidation-secret-exceptions.json) містить
тільки commit/path/rule/line, контрольну суму всього Git blob та обґрунтування;
значення спрацювань не публікуються. Інструмент звіряє blob перед створенням
тимчасового ignore-файла. Wildcard, інші правила та дублікати заборонені;
винятки для відсутніх у джерелі комітів не застосовуються. Загальне правило
`generic-api-key` та інші стандартні правила залишаються ввімкненими,
inline allow і успадкована конфігурація не використовуються.

Свіжі незалежні локальні mirrors містять усі рекламовані refs; refs після
fetch точно збігаються з повторним ls-remote: AvelRen 188, ops 4, ORIGINAL
219. Main усіх трьох джерел не змінилася. Gitleaks 8.30.1 перевірив усю
досяжну історію спочатку без винятків, потім із перевіреним реєстром:

| Історія | Без винятків | Із винятками | Застосовано винятків |

| AvelRen | exit 0, 0 findings | exit 0, 0 findings | 0 |
| AvelRen-ops | exit 0, 0 findings | exit 0, 0 findings | 0 |
| ORIGINAL | exit 1, 13 findings | exit 0, 0 findings | 13 |

[Санітизований receipt](task01-inventory/secret-review-scan-2026-10-11.json)
