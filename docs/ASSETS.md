# Binary asset provenance

Every binary asset committed to the repo (image, font, audio, video) **must** have a
row here: file path, source, license, date added. An asset without a provenance row
must not be merged (enforced in CI — see `.github/workflows`).

## Правило

- Новий бінарний актив → додати рядок сюди в тому ж PR.
- Джерело «знайдено в інтернеті / Pinterest / пошук зображень» без явної ліцензії — **заборонено**.
- Стокове фото (Unsplash/Pexels тощо) — вказати URL і ліцензію.
- ШІ-згенероване — вказати, що згенеровано власником; у Play ставити декларацію «створено за допомогою ШІ».
