## Огляд і межі готовності

Усі п'ять PNG відкрито й переглянуто. Видимих паролів, токенів,
імен користувачів або особистих контактів не виявлено. Перелік PNG chunks
містить лише `IHDR`, `IDAT`, `IEND`: текстових, EXIF або часових metadata немає.
Це опис виконаного огляду, не незалежна правова експертиза.

- Feature містить число 535 і графік; це старе зображення, не поточні дані.
- Icon містить стилізовану літеру A/дорогу.
- `screen-01` містить старий інтерфейс, число 535, дату 26.08 та фото вантажівки
  з видимою емблемою; права на композицію й використання марки треба перевірити.
- `screen-02` рекламує AI-прогноз. Наявність цього тексту не доводить готовності
  чи точності функції в поточному застосунку.
- `screen-03` містить старі черги, час в'їзду та твердження про п'ять країн.

Статус: **архів для перевірки, не публікувати як актуальний комплект**.
Перед використанням потрібні перевірка прав, відповідності поточному UI,
даних і рекламних тверджень та окреме приймання матеріалів Play.
Цей перенос не створює APK/AAB, не підтверджує телефонне приймання,
не завантажує матеріали в Play Console й не змінює production.

## Повторна перевірка байтів

Із кореня репозиторію, для кожного PNG:

```powershell
Get-ChildItem docs/assets/legacy-play/*.png | ForEach-Object {
    git hash-object -- $_.FullName
    Get-FileHash -Algorithm SHA256 -LiteralPath $_.FullName
}
```

Git blob SHA має збігатися і з таблицею, і з деревом вихідного commit;
SHA-256 — з таблицею. Під час перенесення збіг усіх п'яти blob SHA,
SHA-256, розмірів PNG та кількості байтів перевірено локально.
