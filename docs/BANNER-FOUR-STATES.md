# Плашка після перевірки власника — 24–25.09.2026

Власник виявив миготіння версії замість плашки та перехід
«Немає зв'язку» → «Немає інтернету» при вимкненні мережі.

- Виправлено `HeaderRow`: невизначений стан головної плашки більше не
  підставляє `VersionHeader`. Версія залишається лише на екранах, де плашка
  навмисно вимкнена, та в налаштуваннях.
- Видимих станів п’ять: зелений кружок «Сервер онлайн», червоний
  «Немає інтернету», жовтий «Слабкий інтернет», жовтий ключ «Технічні роботи»
  та жовтий ключ «Перезапуск сервера».
- UNKNOWN/помилка API/застарілі або відсутні дані залишаються окремими
  внутрішніми станами, але не додають написів на головний екран.
  Невідомий стан тимчасово приховує плашку; він не означає онлайн чи ремонт.
- Технічні роботи потребують чинного підтвердженого серверного вікна.
  Якщо за наявного інтернету API перестає відповідати всередині вже
  підтвердженого вікна, показується «Перезапуск сервера». Сам timeout поза
  таким вікном не означає перезапуск. Рамка не повертається.
- Додано регресійні тести п’яти написів і переходу offline/online.

Збірка й телефонна перевірка цієї правки ще не виконані.
