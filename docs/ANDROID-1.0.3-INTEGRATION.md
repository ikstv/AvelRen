# Інтеграція інтерфейсу 1.0.3 — 02.10.2026

Погоджений телефонний інтерфейс перенесено з гілки
`codex/home-yellow-frame-test`, коміт `219a87f2e892f899e2707d8e4ead8466acf6b645`.
Серверний модуль і короткі голосові назви — з
`codex/experimental-surge-monitor`, базовий коміт `e2c5d2eddf9d90bec326fbc4f8bb14b6d623edd7`.
Початкове походження Android-файлів збережено у ANDROID-PROVENANCE.json.

## Узгоджена поведінка

- Темна тема за замовчуванням, світла з червоним акцентом; погоджені рамки,
  назви екранів, підпис джерела та рядок паузи збережено.
- «Прогноз черги» використовує серверні підписки, максимум 5 КПП на інсталяцію.
  Сервер серіалізує зміни одного пристрою до захоплення блокування КПП:
  паралельні запити до різних КПП не обходять ліміт.
- Фільтр країн, круглі позначки та підтвердження видалення збережено.
- «Відстежується» означає підписку. При помилці оновлення показано «Немає зв’язку».
  Для КПП без моделі прямо зазначено доступність лише фактичного сповіщення.
- Прогноз і фактичний початок — різні повідомлення; активні події мають
  «Зрозуміло», що спочатку зберігає ACK локально, потім запускає доставку серверу.
- Голос обов’язковий для цього моніторингу, без перемикача чи окремого описового
  блоку. Старий локальний вибір «без голосу» не вимикає нову поведінку.
  Пошкоджений локальний журнал блокує озвучення, зберігаючи захист ACK.
- TTS і audio focus використовують USAGE_NOTIFICATION_EVENT. Гучність медіа
  не визначає гучність голосу; беззвучний режим та «Не турбувати» враховуються.
  Перевага локальному uk-ua-x-hfd-local, темп 0.88, висота 1.02;
  запасний варіант — встановлений український голос без мережі.
- «Функція в розробці» залишається. 99% precision/recall не підтверджено.

## Перевірки та межі

Реально спостережено RED: новий Android-тест голосу завершився AssertionError;
API дозволяв шосту підписку (200 замість 409). Після виправлення Android
JVM/assemble/lint успішні; 78 API-тестів успішні, включно з шістьма паралельними
запитами, зміною наявної підписки й звільненням місця після видалення.

Це локальні результати для робочої гілки. Вони не підтверджують CI нового коміту,
production-розгортання, голос на заблокованому телефоні чи Google Play.
Технічний VoiceProbeActivity доступний лише в тестових варіантах APK.
Погоджений wait DTO/UI-контракт збережено; застосовані міграції не редагувалися.
Релізний опис власник редагує окремо, публікацію не виконано.

Рев’ю інтеграції: додано явне повідомлення про недоступні/застарілі дані
конкретного КПП, підписані блоки «Прогноз» і «Фактичне зростання», часове
вікно актуального прогнозу та величину фактичного зростання (якщо є).
Добовий графік доступний окремою дією «Черга на добу →» у картці КПП.
