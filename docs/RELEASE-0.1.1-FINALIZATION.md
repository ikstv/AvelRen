## Погоджений екран налаштувань — ще реалізувати

Доручення власника: після поточного серверного етапу, до фінальної збірки.

1. «Про додаток» над адмініструванням: встановлена версія з BuildConfig,
   історія змін за версіями, узгоджена з GitHub release notes.
2. «Адміністрування»: зберегти нинішню піктограму.
3. «Політика конфіденційності»: відкрити чинну політику.
4. Усі три кнопки окремо обвести жовтими рамками за зразком рамок країн
   у виборі КПП: використати наявні дизайн-токени, товщину й заокруглення.
5. Стрілки праворуч ЗАЛИШИТИ: останнє уточнення власника скасовує попередню
   пропозицію прибрати їх. Заголовок «Налаштування» не додавати.

## Порядок приймання

Серверні зміни та їхні перевірки → екран налаштувань і повний перелік змін →
CI/злиття → чиста main-збірка → перевірка власником на телефоні →
GitHub Release з остаточними файлами/хешами → той самий AAB і погоджений
опис у Google Play. Публікація залишається після приймання, не до нього.
