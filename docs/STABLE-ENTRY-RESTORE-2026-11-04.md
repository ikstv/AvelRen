# Відновлення часу єЧерги — 04.11.2026

Ця revision-фіксація описує зміни коміту `6de032a` для відновлення двох
значень часу в ланцюжку єЧерга → collector → PostgreSQL → API → Android.

Collector зберігає текст заголовка очікування з основної відповіді workload
у `observations.source_wait_text`, а час останнього стабільного автомобіля
отримує з details endpoint, пропускаючи записи з icon 4 та 10. Агрегований
розрахунок `wait_estimate` не змінювався. Додано міграцію 018 і передачу полів
через API та Android-модель; персональні дані автомобілів не зберігаються.

Перевірки: локальні backend-тести та ізольований Docker collector/spool
fixture пройшли. Production, deployment і CI цим записом не приймаються.
