# Ідентифікатор інсталяції для очікуваного Admin-підтвердження

## Призначення

Коли API повертає `awaiting_approval`, Android показує `device_id` цієї
інсталяції. Власник може звірити його з записом на сервері перед окремою,
контрольованою операцією підтвердження або переприв’язки.

## Межі безпеки

Показується лише UUID-ідентифікатор. `device_secret` не показується, не
копіюється і не передається через UI. Сам ID не надає доступу: для
автентифікованого API-запиту потрібна пара ID і секрет.

Зміна не виконує server-side approval, unlock, rebind, deployment або зміну
PIN. Кожна така production-операція потребує окремого явного GO після звірки
точного ID.
