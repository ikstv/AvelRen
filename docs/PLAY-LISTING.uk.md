# Канонічний опис сторінки Google Play

**Статус: чернетка для ручного перенесення в Play Console.** Це постійний
опис застосунку, а не примітки до версії. Окремі зміни релізу беруться з
[RELEASE-0.1.2-DRAFT.md](RELEASE-0.1.2-DRAFT.md).

## Короткий опис — 59 / 80

Черги для вантажівок: поточні дані, динаміка та сповіщення.

## Повний опис — 717 / 4000

AvelRen допомагає водіям вантажівок стежити за чергами на пунктах пропуску:
переглядати поточні показники, їхню динаміку та отримувати сповіщення за
обраними умовами.

Застосунок отримує дані через власний API AvelRen. Він є незалежним,
неофіційним застосунком і не представляє державні установи. Перед поїздкою
звіряйте важливу інформацію з офіційним сервісом єЧерга.

У застосунку доступні:

• моніторинг вибраних пунктів пропуску;
• історія та динаміка виміряних даних;
• сповіщення за обраними умовами;
• налаштування стану сервера та доступу Admin для власника.

Прогнози, якщо показані, є окремими оцінками й не замінюють виміряні дані.
Не плануйте перетин кордону, покладаючись лише на інформацію в застосунку.
