# Чернетка опису GitHub Release 0.1.1

Це робочий текст для майбутнього GitHub Release, не опублікований реліз.
Кожну зміну й результат перевірки окремо ведемо в
[журналі 0.1.1](RELEASE-0.1.1-CHANGES.md). Перед публікацією звірити цей
текст із фактично встановленим APK, сервером і Google Play.

## Робочий текст

### Прогноз черги

- Додано повноекранний погодинний прогноз на наступні 24 години з вибором КПП.
- Прогноз починається зі свіжої виміряної кількості автомобілів і оцінює
  наступні години за історичними змінами схожих ситуацій.
- Якщо поточний вимір застарів або історії недостатньо, застосунок не видає
  число як надійний прогноз.
- На шкалі видно дати після опівночі; з підписів прибрано зайві «Київ» і
  «київський час». Прибрано технічні числа про схожі години.
- Прогноз позначено як попередній: AI-модель ще в розробці.

### Моніторинг і стан зв’язку

- Моніторинг завантажується після реєстрації пристрою; пороги й заданий час
  запитуються паралельно.
- Очікування запиту обмежено; після помилки є кнопка повтору, а останній
  повний список не стирається.
- Повторні одночасні запити не накопичуються, а після втрати авторизації
  інсталяція може відновити з’єднання.
- Плашка без рамки розрізняє «Сервер онлайн», відсутність інтернету та
  нестабільний інтернет. Невизначений початковий стан не видається за збій.
- Повідомлення про перезапуск не з’являється через саму лише затримку даних.

### Налаштування та Admin

- У налаштуваннях додано «Про додаток», «Адміністрування» і
  «Політика конфіденційності» як окремі кнопки в жовтих рамках.
- «Про додаток» показує встановлену версію та історію змін.
- У вкладці «Сервер» видно кількість пристроїв, активних за останні
  24 години. Це загальне число без даних окремих пристроїв.
- Вхід Admin призначено для однієї підтвердженої інсталяції з PIN;
  чужа інсталяція блокується на 24 години окремо від власника.

### Конфіденційність та оновлення

- Неактивні записи пристроїв автоматично очищаються після 90 днів;
  відповідні розділи політики конфіденційності оновлено українською й
  англійською без вимоги писати на особисту пошту.
- Удосконалено завершення оновлення через Google Play: завантажене оновлення
  можна встановити пізніше, після повернення до застосунку чи повторної
  спроби.

## Умови остаточного тексту

- Підтвердити роботу Admin саме на телефоні власника та перевірити
  24-годинне блокування чужої інсталяції без розкриття PIN.
- Розгорнути публічний агрегований endpoint активних пристроїв після
  окремого дозволу; звірити число у вкладці «Сервер».
- Пройти CI, зібрати APK/AAB з чистої `main`, звірити встановлений APK за
  SHA-256 і пройти сценарії власника. Якщо якийсь пункт не пройде, виправити
  його або вилучити з тексту до публікації.
- Не додавати в цей опис розсилку релізного push, щоденний Admin-звіт або
  завчасне попередження про технічні роботи до їхньої окремої перевірки.
