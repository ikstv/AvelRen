# Єдиний опис релізу 0.1.1

Канонічний текст приміток українською:
[`apps/android/app/src/main/assets/release-notes/v0.1.1.uk.txt`](../apps/android/app/src/main/assets/release-notes/v0.1.1.uk.txt).
Історичний 0.1.0 має окремий
[канонічний файл](../apps/android/app/src/main/assets/release-notes/v0.1.0.uk.txt):
його дослівно звірено з живим випуском Google Play і синхронізовано з
GitHub Release `v0.1.0` 24.09.2026.

Застосунок читає обидва файли на екрані «Про додаток». Під час майбутньої
публікації **ті самі символи, рядки й порядок** треба використати як body
GitHub Release `v0.1.1` і як український текст «Що нового» Google Play.
Назва версії й мовні теги Play — окремі поля, не частина приміток. Тег і
реліз 0.1.1 ще не створено.

Текст навмисно вкладається в [ліміт Google Play — 500 символів Unicode
на мову](https://support.google.com/googleplay/android-developer/answer/9859348?hl=en).
Докладний перелік **кожної** правки й перевірки зберігається в
[журналі 0.1.1](RELEASE-0.1.1-CHANGES.md), який не замінює короткі однакові
примітки для користувача.

Перед публікацією перевірити Admin на телефоні власника, розгорнути endpoint
активних пристроїв після окремого дозволу, пройти CI, зібрати APK/AAB з
чистої `main`, звірити встановлений APK за SHA-256 і пройти сценарії на
телефоні. Якщо зміст зміниться, спочатку виправити канонічний файл, потім
перезібрати APK й тільки після цього копіювати текст у GitHub і Google Play.
