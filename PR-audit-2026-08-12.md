## Summary

Remediation of the 2026-08-12 code audit. Closes the two highest-consequence
findings (H-1, H-4) and eight medium ones across backend, deploy/DR and the
Android client. Each fix ships with a regression test or contract check; no
production behaviour is changed silently.

## Changes

**Data & disaster recovery**
- **H-1** — Add `deploy/restore-allowlist-contract-test.py`: a static CI check
  that fails when the restore engine's hardcoded relation allowlist drifts from
  the schema (`schema_verify._TABLES_V` + migration sequences). Previously a new
  migration would make production restore abort *after* `dropdb`, mid-DR.
- **M-13** — `restore-production.sh` now takes a best-effort `pg_dump` snapshot
  of the current database *before* it is dropped (never blocks restore if the DB
  is corrupt). Covered in the contract (23 cases) and integration tests.
- **M-7** — `forecast.py` buckets seasonality in `Europe/Kyiv` (SQL + Python),
  so DST transitions no longer smear the weekday/hour signal.

**Resilience & DoS**
- **M-9** — Global handler maps `OperationalError`/`PoolTimeout` to `503 +
  Retry-After` instead of a raw 500 on every public/read path.
- **M-4** — Rate limiter now evicts buckets whose newest hit is older than the
  window, not just empty ones — fixes unbounded memory growth under IP spread.
- **read-rate-limit** — Public GET endpoints (`/checkpoints`, `/workload`,
  `/history`, `/forecast`, `/forecast/quality`) are now rate-limited.

**Backups & notifications (ops)**
- **M-11** — `backup.sh` preflight now requires the rclone remote to be of type
  `crypt`, refusing to ship plaintext dumps off-host.
- **M-12** — Watchdog raises `backup_stale` when no successful backup in 36h.
- **M-10** — Watchdog uses a per-kind FCM `collapse_key` and disables dead admin
  tokens, so health alerts no longer overwrite each other or retry forever.

**Android**
- **H-4** — `DeviceStore` credential store init is now thread-safe
  (double-checked locking), preventing a cold-start crash / credential loss.
- **M-16** — Inactive ETA targets are filtered out of `list_eta_targets`.

## Tests

- Updated contract tests: backup (18 cases), restore-production (23 cases) and

- Verified locally: `ruff` clean; all fakeable deploy contract tests green;
